# Tool-for-medical-Images

A **Tkinter-based** tool for medical image processing, developed as a mini project for Manipal School of Information Sciences (December 2022).

***

## Overview

This project provides a simple graphical user interface (GUI) tool for processing medical images using Python libraries like OpenCV, Pillow, and Tkinter. The tool is designed to facilitate medical image processing tasks, such as region selection, cropping, and basic manipulation, making it accessible for educational and research purposes in the medical imaging domain.

***

## Features

- **Interactive ROI Selection:** Select regions of interest (ROI) on medical images for focused processing.
- **Image Cropping:** Crop images to the selected ROI.
- **Image Manipulation:** Basic image processing functionalities using OpenCV and Pillow.
- **User-friendly GUI:** Built using Tkinter for easy interaction without command-line inputs.
- **Supports common medical image formats:** Processes images suitable for medical analysis.

***

## Technologies and Libraries Used

- **Python 3**
- **Tkinter:** For building the graphical user interface.
- **OpenCV:** For image processing functions like ROI selection, cropping, and manipulation.
- **Pillow:** For image handling and enhancements.
  
***

## Installation  

1. Clone the repository:
   git clone https://github.com/Vishalkompalli/Tool-for-medical-Images.git
   cd Tool-for-medical-Images
   ```

2. Install the required Python libraries:
   pip install opencv-python pillow
   ```

3. Run the tool using Python:
   python main.py
   ```

***

## Usage

- Launch the application.
- Load a medical image from your local directory.
- Use the mouse to select the region of interest.
- Apply image processing operations through the GUI options.
- Save or export the processed images as needed.
